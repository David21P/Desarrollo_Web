# Hoja de Trabajo 1 - Excursión a Antigua Guatemala

## Descripción del proyecto
Página web informativa desarrollada en HTML que promociona una excursión
turística a Antigua Guatemala, ciudad colonial declarada Patrimonio de la
Humanidad por la UNESCO. Incluye una descripción del lugar, una galería de
imágenes, una tabla con el itinerario de la excursión y una lista de
actividades adicionales que se pueden realizar en el destino.
