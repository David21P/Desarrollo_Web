# Hoja de Trabajo 2 - Excursión a Antigua Guatemala (con estilos)

## Descripción del proyecto
Evolución de la Hoja de Trabajo 1: se mejoró la semántica y accesibilidad del
HTML (uso de `figure`/`figcaption`, `caption` y `scope` en la tabla, enlace
para saltar al contenido, encabezado con `aria-labelledby`) y se agregó una
hoja de estilos `style.css` con una paleta inspirada en la arquitectura
colonial de Antigua Guatemala (adobe, piedra encalada y detalles dorados).
Incluye tipografía personalizada, un encabezado fijo de navegación, tarjetas
con efecto de arco en la galería, tabla estilizada y diseño responsivo
mediante media queries para tablet y móvil.
